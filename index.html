I work on robust, data-efficient visual perception: DETR-based object detection, semi-supervised learning and report generation with LLMs. My current work focuses on medical image analysis, explainable AI and few-shot segmentation. My first-author work has appeared at CVPR, ICCV and ICDAR.

I did my doctoral research at DFKI with Prof. Dr. Didier Stricker, funded by DAAD, leading work on semi-supervised detection, multimodal document layout analysis in the LUMINOUS project and medical anomaly detection in AIRISE. As an Applied AI Scientist at Tensorlake, I built document intelligence systems and led VLM integration.

My long-term goal is agentic AI that can understand, reason and act on visual information.

Semi-supervised object detection

ICCV 2025Featured

STEP-DETR: Advancing DETR-based Semi-Supervised Object Detection with Super Teacher and Pseudo-Label Guided Text Queries

T. Shehzadi, K. A. Hashmi, S. Sarode, D. Stricker, M. Z. Afzal

  • Super Teacher generates higher-quality pseudo-labels for the student.
  • Pseudo-Label Text Queries balance confidence across common and rare categories.
  • Denoising Text Guided Object Queries use contrastive learning to separate objects from background.
  • Reaches 45.4 mAP with 10% labeled data, 1.9 above Semi-DETR.

Projects

Current research, applied work and thesis topics.

Current work

Explainable AI

I study how to evaluate explanation methods such as saliency maps, to tell whether an explanation reflects what a model actually relies on.

Report generation with LLMs

I explore how LLMs can turn visual findings into clear, structured reports that people can check against the image.

Few-shot medical segmentation

I work on segmenting structures in medical images from only a few annotated examples.

Applied projects

Small, occluded and rare objects

Generic object detection in challenging visual environments

Detectors often struggle when objects cover only a few pixels, are partly hidden, or barely appear in the training data. This work strengthens spatial reasoning in dense scenes, recovers obscured objects from contextual cues, and stabilizes confidence for rare classes, so detection stays consistent in crowded scenes and long-tail distributions.

Small objectsOcclusionLong-tail detection

Document parsing

Unified document parsing with fine-grained element detection

Complex documents pack many visual components into dense layouts. Beyond text blocks, tables, figures and forms, this pipeline handles citations, handwritten and digital signatures, strikethrough detection and removal, stamps, watermarks and other fine-grained elements that matter in legal, academic and financial documents.

Layout analysisSignatures and stampsStrikethrough removal

Student projects

Master's thesis topic

An evaluation metric for explainable AI

Saliency maps are widely used to explain vision models, but judging their quality is still hard. This thesis develops and tests a metric for evaluating such explanations.
